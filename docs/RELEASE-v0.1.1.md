# DuckDuckMove v0.1.1 · 首个公开测试版

Windows 11 动图头像工具：内置小鸭 GIF，也可选择自己的动图。

## 下载与安装

- **安装版**：下载 `DuckDuckMove-0.1.1-x64.msi`，双击安装。包含开始菜单快捷方式，可选桌面快捷方式，支持系统卸载。
- **免安装版**：下载 `DuckDuckMove-0.1.1-win-x64.zip`，解压后运行 `DuckDuckMove.exe`。
- `SHA256SUMS.txt` 用于核对下载文件完整性；Source code 是源码。

支持 Windows 11 x64，两种版本均无需另装 .NET。应用和恢复头像时需要管理员授权。

## 功能

- 内置透明背景小鸭 GIF，启动即可预览。
- 选择或拖入 GIF，登录界面 / 开始菜单布局示意。
- 浅色、深色及跟随系统主题。
- 保留首次原头像备份，支持恢复原头像和 Windows 默认头像。
- 写入读回核对、失败回滚和未完成操作恢复。

## 测试版说明

已通过 21 项核心测试、动图播放与 UI 交互测试、MSI 静默安装和卸载测试。**真实账户写入的 UAC → SYSTEM 服务流程、Windows 登录界面动画及重启后的保留情况尚未实机验证。** 系统版本与策略可能影响效果，应用内预览不保证系统界面播放动画。

文件尚未进行代码签名。卸载会保留头像素材和备份；需要还原头像时请先在软件中恢复。
