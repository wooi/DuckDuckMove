# DuckDuckMove v0.1.3 · Multilingual preview

## English

Bring your avatar to life. This update includes:

- Six UI languages: English, Simplified Chinese, Traditional Chinese, Japanese, Spanish and Portuguese. Follow Windows display language by default, or choose from the globe menu. Manual choices are saved and apply immediately.
- Automatic Start menu reload after applying or resetting an avatar, to help the bottom avatar pick up the change without a PC reboot. The menu may briefly close; the visual result still needs verification on different Windows versions.
- A cleaner footer with only **Reset to default** and **Apply avatar**, plus compact appearance and language icons.
- The built-in duck GIF, first-frame app icon, six-language READMEs and matching screenshots.

**Download from Assets below:**

| File | Use |
| --- | --- |
| `DuckDuckMove-0.1.3-x64.msi` | Installer with Start menu shortcut, optional desktop shortcut and Windows uninstall support. |
| `DuckDuckMove-0.1.3-win-x64.zip` | Portable: extract and run `DuckDuckMove.exe`. |
| `SHA256SUMS.txt` | SHA-256 hashes for verifying the two downloads. |

Windows 11 x64 is required. .NET is included. Applying/resetting requires administrator approval. Close the old app before updating; portable users should extract into a new folder. Assets and backups remain after uninstalling; reset the avatar first if desired. The MSI wizard remains Chinese; the application selects its language independently.

**Preview / unsigned:** this changes the current user's local Windows avatar, not the cloud Microsoft account picture. Synchronization of the Microsoft account card is unsupported. Animation and automatic refresh may vary by Windows build/account. Core and hidden UI/language tests pass; hidden tests do not prove real account-writing or visual compatibility. The v0.1.1 installer was integration-tested; equivalent full real installation and account testing for this release is still pending. GitHub's Source code archives are not runnable packages.
