# DuckDuckMove 0.1.1 技术决策

## 项目结构

- `DuckDuckMove.Core`：GIF 结构验证、头像状态模型、备份/事务/回滚流程，不依赖 UI。
- `DuckDuckMove.App`：WPF 界面、Windows 注册表适配、受保护文件存储、UAC broker、SYSTEM 服务。
- `DuckDuckMove.Tests`：独立控制台测试器，可注入备份/写入/读回/回滚故障。

## 一次操作

1. UI 在普通用户上下文读取 GIF，验证帧数/尺寸/结构并通过 WPF 解码。使用预览副本避免原文件随后改变。
2. UI 调用同一 EXE 的 broker 模式，通过 UAC 获取管理员权限。
3. Broker 核对 UI 进程 ID、启动时间、会话和可执行路径，从 UI 进程令牌读取目标 SID。目标不是提升后可能不同的管理员账户。
4. Broker 建立受保护目录，限制普通用户写入并抑制所有者隐含 WRITE_DAC 权限。使用新建文件流复制素材与程序，避免复制源文件 ACL。
5. 将请求写入受保护 JSON，创建需求启动的临时 LocalSystem 服务。服务运行已复制到受保护目录中的单文件 EXE。
6. 服务获得独占写锁，恢复遗留事务，保存首次原始备份和本次变更前快照，修改 `Image数字` 值，再读回核对。
7. 失败则恢复本次快照；回滚失败则保留 pending.json。成功或失败均写入结果文件。
8. 服务停止；broker 删除服务注册和请求文件，界面显示结果。超过等待时限也标记删除，SCM 在服务停止后完成删除。

## 固定边界

- 固定 Registry64、HKLM、`SOFTWARE\Microsoft\Windows\CurrentVersion\AccountPicture\Users\<SID>`；不接受任意注册表路径。
- 修改范围只包含 `Image` 后跟 ASCII 数字的头像值，保留其他值和子键。
- 头像键不存在时使用固定尺寸集合；恢复时删除新增头像值，仅在原键不存在且当前键完全为空时删除键。
- 常规路径支持 apply/default/restore，以及中断后的 recover；无 shell、任意命令或任意服务执行接口。
- 请求与服务 EXE 位于受保护目录；服务不接收用户可写目录中的脚本。
- GIF 不重新编码，不依赖 FFmpeg，不调用云端接口，不使用 PsExec，不常驻后台。

## 恢复含义

首次备份保存原注册表值及可读取的原图片文件，并记录 SHA-256。恢复原头像优先还原原始路径和类型；原文件已不一致时改用校验过的备份路径。原本就缺失的图片只能保留原路径状态，不能重建不存在的图片内容。

恢复默认不删除全部账户配置，而是将头像值指向本机 `Microsoft\User Account Pictures` 中对应尺寸的系统图片，缺少某尺寸时使用 `user.png` 等回退文件。
